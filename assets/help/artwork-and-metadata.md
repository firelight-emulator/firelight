# Artwork & metadata

Firelight fills in each game's **name**, **icon**, **box art**, and details (developer, publisher,
genre, release year, region) automatically when it's added to your [Library](/library). You can
also customize the artwork yourself.

## Automatic artwork

Right after a game is added, its real name and art appear on their own — no setup required. This
works offline using data that ships with the app.

## Changing a game's artwork

**Right-click a game** and choose **Change artwork**. In the picker you can:

- Switch between artwork types — **Icon**, **Box Art**, **Logo**, **Hero**.
- Pick from **Your artwork** (art already known for the game).
- Search **SteamGridDB** for more options and click one to apply it.
- **Import from file…** to use your own image.

Your choice updates the tile immediately and sticks across restarts.

## Using SteamGridDB

SteamGridDB is a community art database. To search it you need a free API key:

1. Get a key at
   [steamgriddb.com/profile/preferences/api](https://www.steamgriddb.com/profile/preferences/api).
2. Open **Change artwork** on any game and paste the key into the SteamGridDB field.

Once the key is saved, searches run automatically. The search box is pre-filled with the game's
name — if the results aren't right, **edit the search term** and search again. Results are grouped
by matching game, so you can tell which title each image belongs to.

## Renaming a game

If you rename a game yourself, Firelight remembers your choice and won't overwrite it with the
automatic name later.
