# Controllers

Open [Controllers](/controllers) to set up your gamepads and how their buttons map to each system.

## Connecting a controller

Plug in (or pair) a controller and Firelight detects it. Most standard gamepads work out of the
box. Your keyboard can also be used as a controller.

## Profiles & button mapping

A **profile** defines how a physical controller's buttons and sticks map to a console's inputs.
You can:

- Edit the mapping for any controller.
- Keep separate profiles and pick a **preferred controller per platform**, so your fight stick is
  used for arcade titles and your gamepad for everything else.
- Override the mapping for a specific game when it needs something unusual.

## Shortcuts

Beyond game inputs, you can bind **shortcuts** — things like opening the menu, toggling fast
forward, rewinding, or taking a screenshot — to button combinations.

## Special devices

Some systems support more than a standard pad. Firelight can present a core's supported device
types (for example a **Mouse** or **Light Gun**) per port, with their own bindings — including using
an analog stick as a pointer. Where a system offers variants, you can choose which one a game uses.

## Tips

- If a controller isn't responding, re-open the Controllers page to let Firelight re-detect it.
- Changes to mappings take effect immediately — no restart needed.
