# Cheats

Firelight includes a built-in cheat system for supported games.

## Turning cheats on and off

Cheats are managed per game. Each cheat can be toggled on or off independently, and your choices
are remembered for that game. Enabled cheats apply while you play and can be switched on or off
live.

## How it works

- Many cheats work by writing values into the game's memory each frame.
- Some code formats (such as Game Genie) are handed to the emulator core to apply.

Either way, you just toggle the ones you want.

## Hardcore mode

Cheats are **disabled while hardcore achievements mode is on** — see **Achievements**. Turn
hardcore off to use cheats.

## A note on compatibility

Cheats are game- and system-specific. A code written for one region or revision of a game may not
work on another. If a cheat doesn't seem to do anything, double-check it matches your exact version
of the game.
