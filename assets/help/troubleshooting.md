# Troubleshooting

Common issues and where to look.

## A game won't appear in my library

- Confirm its folder is added under [Settings](/settings) → **Directories**.
- Give the scan a moment — large folders take a little time.
- Make sure the file is a supported ROM for a system Firelight can emulate.

## A game shows the wrong name or no art

- Art and names fill in shortly after a game is added. If one is missing, the game may not be in
  the bundled metadata.
- You can set it yourself: right-click the game → **Change artwork**, and rename it directly. See
  **Artwork & Metadata**.

## Rewind or cheats aren't available

Both are **disabled while hardcore achievements mode is on**. Turn hardcore off under
[Settings](/settings) → **Achievements** to use them. See **Achievements**.

## A game runs but has no sound, or stutters

- Check **Audio / Video** and **Emulation** settings.
- For stutter or screen tearing, try a different **frame pacing / sync** option under **Emulation**.

## PlayStation Portable (PSP) games won't start

PSP emulation needs a set of runtime assets. Firelight seeds these automatically on first run; if
PSP games still fail, make sure the app finished setting up after installation and try again.

## Where are my files?

Firelight keeps your data in its application data directory, including:

- **Saves** and **suspend points**
- **Screenshots** and **clips**
- Your **library**, settings, and achievement data

You can open the relevant folders from [Settings](/settings) → **Directories**.

## Still stuck?

Check the project's community and issue tracker online for help, or report a bug with details about
your system and the game you were playing.
