# The Library

The **Library** is your collection of games. Firelight builds it for you by scanning the folders
you point it at, then keeps it in sync as you add and remove files.

## Adding games

Open [Settings](/settings) → **Directories** and add any folder that holds your ROMs. You can add
several. Firelight will:

- Scan those folders and add every game it recognizes.
- Watch them, so games you drop in later show up on their own.
- Re-check periodically, so nothing gets missed.

Games are identified by their content, not their filename — so renaming a ROM won't create a
duplicate, and the same game keeps its saves and achievements.

## Names, icons, and art

When a game is added it briefly shows its filename, then fills in its real **name**, **icon**, and
**box art** automatically. You can replace any of this yourself — see **Artwork & Metadata**.

## Folders and smart folders

You can organize games into folders:

- **Manual folders** — you decide what goes in them.
- **Smart folders** — you set a rule (by platform, developer, publisher, genre, release year, and
  more) and Firelight keeps them filled automatically. Add a new game that matches, and it appears
  there with no extra work.

Folders can be reordered, colored, and given their own sort order.

## Searching and sorting

Use the search bar to jump to a game by name. Sorting (by name, recently played, and so on) can be
set per folder and is remembered.

## Right-click actions

Right-click a game for quick actions, including **Change artwork** — see **Artwork & Metadata**.
